Simulateur de cascade (graphe jouet)

Graphe synthétique de 240 paquets. Un paquet compromis infecte chacun de ses dépendants avec la probabilité p. Un paquet audité est immunisé. Résultats illustratifs : ils dépendent du modèle, pas de données réelles.

Vert : paquets audités par la stratégie choisie. Rouge : compromis. Bleu : sains.

Protection moyenne à budget égal

120 simulations par stratégie, mêmes origines pour toutes.

Règles pour éviter les conflits Git

  • Chacune ne modifie que ses dossiers. Les fichiers communs (README, docker-compose, requirements) passent par une petite PR.
  • Samah commite d’abord le kit de départ et src/blastradius/__init__.py sur develop, puis les autres créent leurs branches.
  • Git ne suit pas les dossiers vides : ajoutez un fichier .gitkeep ou un __init__.py.
